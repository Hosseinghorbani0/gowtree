gowtree — Windows Installer
============================

Welcome! This wizard installs gowtree on your PC.

WHAT YOU GET
  • A modern "tree" command for Windows Terminal / CMD
  • Colors, icons, JSON / Markdown / HTML export
  • Adds gowtree to PATH (optional, recommended)

WINDOWS SMARTSCREEN (first run only)
------------------------------------
Windows may show a blue screen: "Windows protected your PC".

This happens because gowtree is new and not yet code-signed.
It is safe — our source code is public on GitHub.

To continue:
  1. Click  "More info"
  2. Click  "Run anyway"

After many users install, Windows usually stops showing this warning.

REQUIREMENTS
  • Windows 11 (or Windows 10 22H2+)
  • No Administrator rights needed
